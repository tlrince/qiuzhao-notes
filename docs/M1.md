# M1 设计系统与应用外壳

状态：已完成。独立验收日期：2026-09-16。

M1 提供 React/Vite 应用入口、五个业务路由、固定侧栏、顶栏保存状态、响应式断点、空状态、基础图标与按钮组件，以及可访问的原生抽屉和确认框。

界面默认是空工作空间，不加载演示投递，也不会把“尚未保存”误报成已持久化。`/design-system` 是显式的组件预览页，可以查看招聘季外观、保存状态、阶段徽标、抽屉焦点约束和未保存确认。

独立浏览器验收：`npm run test:m1`，共 8 项，覆盖 2032、1440、1024、768、390 五种视口；检查导航、深链接查询参数、刷新/返回、横向溢出、空态、控制台错误、键盘 Tab/Escape、未保存确认和关闭后焦点恢复，全部通过。截图输出到 `artifacts/m1/`。

M1 不实现真实投递、统计计算、IndexedDB 或备份；这些由后续模块负责。页面通过 `AppShell` 接受工作空间、招聘季、保存状态和投递数，后续接入 Repository 时无需改动布局契约。
