# R1 v2 领域契约验收

状态：已完成。独立验收日期：2026-09-17。

## 交付范围

- 新增 `src/domain/v2/`，保留原 M0 v1 契约供现有页面和存储使用；本模块不接触 React 页面、IndexedDB、SQLite 或 Tauri。
- 提供可配置环节与状态定义、颜色/顺序/归档和自定义状态管理。状态语义、阶段分类及面试统计定义变更会递增版本；事件保存定义版本及不可变语义快照。
- 提供进度记录、ProgressEvent、可重复 visit、阶段投影、失败归因、unknown 挂点上下文与“跳过”表格注记。
- 支持按用户录入顺序建链、同日补录、补录并入既有 visit、显式重开并要求原因、原子纠正、事件作废与 commandId 幂等。
- 投递日期与唯一有效的首次“已投递”事件双向校验并同步。Offer 接受/拒绝只可消费尚未决定的 Offer；拒绝 Offer、招聘方淘汰、接受 Offer 和主动退出分别保留语义。
- 投影同时提供当前状态名和历史事件名快照；真实面试触达只根据带有效阶段的面试 visit 计算，不从失败标签推断。
- `createR1MockCases()` 提供重复筛选、重复泡池子、Offer 拒绝、直接跳到二面和未知失败数据；调用方显式创建时才产生，不会被应用默认加载。

## 独立验收

- `npm run test:r1`：27 项通过，含 TypeScript 领域构建。
- `npm run test:m0`：22 项通过，确认旧 M0 契约无回归。
- `npm run build`：TypeScript 检查与 Vite 生产构建通过。

测试覆盖版本快照与语义篡改、日期同步、重复 visit、Offer 决策消费、所有终态重开原因、失败归因一致性、原子纠错、补录和 visit 合并、状态改名、幂等重试、跳过注记及显式事件链校验。

单事件纠错会保留事件链并维护重新开启引用。若某结束事件已有后续重开，不能只把结束事件改成非终态；需先纠正该后续依赖，再移除原结束结果，以免保留没有依据的“重新开启”节点。

## 后续边界

R1 原始交付只包含领域规则和内存 Mock。后续 R2 接入 v1→v2 迁移、IndexedDB/SQLite 持久化与事务；M3 v2 已接入投递详情、状态选择器、日程和原始 JSON 导入；M4 已接入动态进度表和事件历史编辑。v1 代码保留作迁移兼容，当前业务主路由使用 v2 数据。
