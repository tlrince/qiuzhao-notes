# M3 投递管理验收

状态：v1 基础版与 v2 当前工作流均完成独立测试并接入应用。

当前 v2 投递页通过 v2 命令处理列表、搜索/筛选、招聘季范围、草稿与状态记录、详情字段和独立招聘进度网址。原始 JSON 导入先展示全量校验结果和状态分布；确认后只替换选中招聘季，保留其他招聘季并以事务快照留住替换前数据。删除投递需要二次确认，在同一 CAS 事务中清理该投递、进度、日程和旧历史，并保留删除前快照。

详情页可新增、编辑、删除日程，也可将日程标为完成、取消或恢复待办；完成日程不自动推进招聘状态。日程和投递写入均经过 revision CAS 校验。

真实导出的原始 JSON 已全部解析为有效记录，保留原始状态分布和日期语义；解析统计及行为见[原始状态导入验收记录](M3-raw-import.md)。
