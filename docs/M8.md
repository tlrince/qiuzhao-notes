# M8 设置与备份验收

状态：备份与恢复副本流程已完成代码实现和 Web/Mac 命令测试；真实跨端文件往返仍待验收。

## 已实现

- 设置页可导出完整 v2 JSON 快照，包含招聘季、投递、进度事件、定义、日程和偏好，不受页面筛选影响。
- 可选择 v1/v2 备份进行本地校验和预览。预览包含工作空间、来源版本、导出时间、招聘季名称、投递/事件/日程数量；整体替换前要求再次确认。
- 恢复副本可在设置页按时间查看招聘季与记录摘要；选择副本后显示预览并二次确认恢复。
- 副本没有自动清理或固定数量上限。用户可以针对单个副本执行二次确认删除；删除只移除所选 ID，并在 revision-CAS 事务内完成。
- 列表显示副本数量、JSON 序列化后的 UTF-8 字节估算合计和每份估算；这些数字按原始保存数据计算，不代表 SQLite/IndexedDB 的实际磁盘占用。
- Web IndexedDB 的指定副本恢复在同一 readwrite 事务中检查 revision、保存当前快照为新副本并恢复所选数据。普通快照提交不改写副本历史。内存适配器覆盖相同行为。
- SQLite/Tauri 已增加列出恢复副本和指定副本恢复的桥接；恢复命令会校验副本来源 ID，并要求存储层执行原子 CAS。
- Mac 保存成功后记录完成时间；Web 记录浏览器收到下载请求的时间，并明确浏览器不能确认文件最终落盘。并发较早完成的备份不会让时间戳倒退。

## 独立验收

- `npm run test:m8`：15 项命令与存储测试通过，覆盖完整导出、v1/v2 解析、坏数据拒绝、CAS 冲突、指定恢复、用户确认删除、原始 JSON UTF-8 大小估算和删除后重算。
- `npm run test:v2-app`：3 项浏览器流程通过；M8 场景覆盖完整备份导出/预览/整体恢复、恢复副本列表与容量估算、预览、确认回滚、回滚前快照留存和指定副本删除后的计数更新。
- `npm run typecheck`、`npm run build` 与全量 Node `.test.mjs` 文件通过。
- `cargo fmt --check` 和 `cargo check --tests` 通过；`npm run test:mac` 的 16 项 Rust 测试均通过，包括恢复副本单项删除事务。
- `npm run build:mac` 成功重新编译 Tauri 并生成本机 `.app`，因此新增 Rust bridge 已过实际 release 编译；本机产物是 thin arm64、本地 ad-hoc 签名，不是公开分发包。

## 尚未验收

- 尚未在刚打包的 `.app` 中进行人工恢复操作，也没有完成 Mac→Web→Mac 的真实备份文件往返和恢复后统计一致性验证。
