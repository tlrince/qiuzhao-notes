# M10 平台桥接与 Mac 外壳

状态：已完成本地开发验收（2026-09-17）。

本模块增加了 Web/macOS 两套平台能力适配器，以及 Tauri 2 macOS 外壳。网页继续使用 BrowserRouter 和浏览器文件输入/下载；桌面使用 HashRouter、Rust 原生文件对话框、原子写入、系统默认浏览器打开外链、最后路由恢复、原生菜单和窗口生命周期事件。

平台接口位于 `src/platform/`，页面通过 `PlatformProvider` 使用，不直接引用 Tauri API。桌面入口动态加载原生适配器，Web 构建不会加载 Tauri runtime。`src/repositories/storage-contract.ts` 同时冻结了带 revision 的全量快照 CAS 协议，供 M2 持久化适配器实现。

本地 Mac 产物曾于此模块验收时生成：`src-tauri/target/release/bundle/macos/秋招手记.app`，并实际打开检查 WKWebView、Hash 路由、原生菜单和窗口按钮。该次 M10 单独验收时工作空间为空；随后 M2 与 M3 v2 将 SQLite 快照和业务页面接入主应用，因此这句不代表当前 App 仍无业务数据。

独立验收：平台 Node 测试 8/8、Web 文件/下载 Chromium 测试 3/3、M1 + 平台 WebKit 兼容测试 11/11、Rust 验证测试 4/4，均通过。Mac 构建使用 `/Library/Developer/CommandLineTools` 和 rustup stable，未修改 Xcode license。

M10 验收当时没有导入用户投递数据，也没有把外部 JSON 自动当作备份。其后的原始投递 JSON 导入流程会保留状态、显示预览并等待用户确认，具体结果与限制见 `docs/M3-raw-import.md`。
