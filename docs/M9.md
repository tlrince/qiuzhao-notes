# M9 集成验收状态

状态：跨适配器备份往返有独立自动化覆盖；真实 Mac App 与 Windows Web 的最终验收尚未完成。

## 已验证

- `npm run test:m9:backup-roundtrip`：用 fake IndexedDB Web store 和 mock Tauri/native adapter 验证 Web → native → Web 的完整 v2 JSON 往返，涵盖招聘季、投递、进度事件、日程、偏好及关键统计投影。
- 同一测试还验证回传前的第二次修改会同步往返；坏 JSON 和 CAS 冲突不会覆盖目标端当前快照。
- Web/Mac 业务代码使用相同 v2 Snapshot 与 BackupCommands；原生 SQLite 侧恢复副本、revision 和 CAS 另由 `npm run test:mac` 的 16 项 Rust 测试覆盖。

## 尚未验收

- 本测试模拟 Tauri IPC，不是把物理 JSON 文件分别导入刚打包的 Mac `.app` 和部署中的 Windows Chrome/Edge。仍需真实文件往返并比对恢复前后的统计结果。
- 尚未执行目标 Windows 浏览器、macOS WKWebView 关键流程、应用升级后数据保留、生产站点深链和真实托管验证。
- 因此 M9 与整体跨端交付仍标记未完成；见 [plan.md 第 10 节](../plan.md)。
