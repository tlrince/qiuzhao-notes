状态：构建链路已验证，公开发布与双端交付验收未完成。

## 已验证

- `npm run build` 成功生成 Web 静态资源至 `web-dist/`。
- `npm run build:desktop` 成功生成 Tauri desktop 模式前端资源。
- `npm run build:mac` 成功编译 Tauri release 二进制并生成 [秋招手记.app](../src-tauri/target/release/bundle/macos/秋招手记.app)。
- `.app` 通过 `ditto` 压缩为 [arm64 app ZIP](../src-tauri/target/release/bundle/macos/秋招手记_0.1.0_arm64_20260917.app.zip)，包含固定坐标 SVG 箭头、热力图方格修复和表格固定列选中态修复；`unzip -t` 检查无损坏；SHA-256：`f1328be0955b29e098933536d762664d264b00132ac6e29e848d991d49a3be92`。
- 当前 `.app` 是 thin `arm64` Mach-O，无 Team ID。构建完成后对整个 app bundle 执行了 ad-hoc 签名封装，并通过 `codesign --verify --deep --strict`；这只验证本机 bundle 完整性，不是 Developer ID 发布签名，也不能用于公证。Rust target 目前仅安装 `aarch64-apple-darwin`。
- DMG 构建已通过 Tauri 编译和 `.app` bundling 阶段，但本机 `hdiutil create` 报“设备未配置”，因此没有生成 DMG。`--sandbox-safe` 试验可执行 `makehybrid`/`convert`，但 `hdiutil resize -limits` 同样以错误码 6 失败；故障发生在 Finder AppleScript 之前，与 AppleScript 和签名无关。
- `cargo fmt --check` 和 `npm run test:mac`（16 项）通过。
- `deploy/nginx/autumn-notes.conf` 提供根目录静态托管样例，包含 BrowserRouter 回退、入口不缓存、Vite 哈希资源长缓存、缺失静态资源 404。`npm run test:m11:static` 4/4 通过。
